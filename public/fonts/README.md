# Fonts

## Microgramma (licensed)

Microgramma is a commercial font. Drop your licensed files here, then tell the agent to wire them:

- `Microgramma-Bold.woff2` (or `.otf` / `.ttf`)
- `Microgramma-Medium.woff2` (optional)
- `MicrogrammaD-ExtendedBold.woff2` (optional extended cut)

Until those files are present, the site uses **Syncopate Bold** (Google Fonts) — a wide geometric Microgramma-like face with real bold weight for TAYO.
